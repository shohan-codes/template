# Connected activity / design 01

**Family:** [PRD-0004](../../README.md). **Status:** Proposed; original design pending.
**Reference:** [F1](../../../../initial-component-references.md#f1-connected-activity-feed), restricted inspiration only.
**Proposed implementation path:** `packages/pattern/src/activity-feed/connected/01.tsx`.

## Original composition

Use ordered event rows with actor/action, readable time and optional related
content. A subtle decorative continuity rule may support chronology, but do not
rebuild the vendor's dotted avatar spine or its specific attachment arrangement.
Original spacing and emphasis follow this repository's design language.

## Requirements

- Event identity, not row index, controls keys. Preserve caller ordering.
- Attachments belong to their event and have a clear name and authorized action.
  Long names wrap; missing destinations render unavailable text.
- Optional unread meaning has text. Actor presence is a different concept and is
  out of scope unless explicitly supplied and labeled by the caller.
- Avoid interactive whole rows containing nested links/buttons. Each actual
  action has its own visible focus and understandable name.

## Design-specific checks

Verify single-event/no-connector, mixed-length events, optional attachments,
missing actor image, long localized time, loading more and retry. Check connector
alignment without relying on fixed row heights. Apply [family acceptance](../../spec.md#acceptance)
and obtain the independent-design review before implementation acceptance.
